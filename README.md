# 🎮 坦克大战 (Tank Battle)

一个经典的HTML5坦克大战游戏，使用纯HTML、CSS和JavaScript开发。

## 🎯 游戏特色

- 🕹️ 经典坦克战斗玩法
- 🎨 精美的像素风格图形
- 🧱 可破坏的砖墙和不可破坏的钢墙
- 📈 多关卡系统，难度递增
- 💯 计分系统
- ❤️ 生命值系统

## 🎮 操作说明

- **方向键** `↑` `↓` `←` `→` 或 **WASD** - 移动坦克
- **空格键** - 发射子弹

## 🚀 如何运行

1. 克隆仓库到本地：
```bash
git clone https://github.com/YOUR_USERNAME/tank-battle.git
```

2. 打开 `index.html` 文件即可在浏览器中运行游戏

或者直接访问 GitHub Pages 在线游玩（如果已启用）。

## 🎲 游戏规则

- 消灭所有敌方坦克即可进入下一关
- 每消灭一辆敌方坦克获得100分
- 玩家有3条生命
- 避开敌方子弹和墙壁
- 砖墙可以阻挡坦克但可以被子弹摧毁
- 钢墙不可被摧毁

## 🛠️ 技术栈

- HTML5 Canvas
- 纯JavaScript（无外部依赖）
- CSS3 动画和样式
